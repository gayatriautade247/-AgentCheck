# -AgentCheck
IntelAgent is a multi-agent AI research platform that investigates complex questions, verifies information from reliable sources, and generates evidence-based answers. It evaluates accuracy, reliability, robustness, evidence quality, hallucinations, and failure recovery to ensure answers are transparent, trustworthy, and defendable.

How It Runs
Open the project folder in VS Code.
Open the index.html file.
Right-click and select “Open with Live Server”.
The AgentCheck website opens in the browser.
Enter a task/question and click Run Evaluation.
JavaScript processes the input and displays evaluation scores.
The website shows test scenarios, consistency, recovery, and the final evaluation score.
